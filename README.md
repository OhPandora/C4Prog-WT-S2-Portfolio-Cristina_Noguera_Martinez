
# Phase 3 – Component Selection

## 1. Header with Navigation on Right

- **Source:** ScreenCraft Components – Headers.
- **Description:** A header with the website logo and site name aligned to the left, and the navigation area aligned to the right.
- **How it will be used:** This component will be used as the main header of the portfolio dashboard. It will provide navigation links to Home, Phase 1, Phase 2 and Phase 3.
- **TailwindCSS features:** Flexbox, spacing, alignment, text styling and responsive layout.

## 2. Navigation

- **Source:** ScreenCraft Components – Headers.
- **Description:** Navigation links integrated into the main header.
- **How it will be used:** It will allow users to navigate between the home page and the three portfolio phases.
- **TailwindCSS features:** Flexbox, spacing, hover effects and responsive layout.

## 3. Vertical Cards

- **Source:** ScreenCraft Components – Cards.
- **Description:** Simple vertical cards with a header, content area and footer.
- **How it will be used:** Cards will display information and links to the different portfolio phases.
- **TailwindCSS features:** Flexbox, borders, padding, background colours and spacing.

## 4. Simple Footer

- **Source:** ScreenCraft Components – Footers.
- **Description:** A footer with the site name, copyright information and navigation links.
- **How it will be used:** It will appear at the bottom of the portfolio dashboard and provide copyright information and useful links.
- **TailwindCSS features:** Flexbox, spacing, borders, text colours and responsive layout.
